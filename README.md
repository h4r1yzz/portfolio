# Harry Chandra — Portfolio

A minimal editorial developer portfolio built with Next.js, TypeScript, and Tailwind CSS.

**Live:** [portfolio-ten-murex-58.vercel.app](https://portfolio-ten-murex-58.vercel.app/)

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4

## Pages

- `/` — homepage index
- `/about` — work, education, resume
- `/projects` — project details
- `/stack` — tools

## Quick start

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `pnpm dev` — development server
- `pnpm build` — production build
- `pnpm lint` — ESLint
- `pnpm start` — production server
